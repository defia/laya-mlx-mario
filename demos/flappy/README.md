# Laya Flappy · 本地终端 demo

小鸟的每一步都由 Laya（`aac6fef/laya-multilingual-mlx`，FP16，本地 MLX 推理）做出真实决策：
一次 `Agent.predict` 批量回答三个类型化问题——

| 面板显示 | 实际含义 |
|---|---|
| 拍翅 / 滑翔 | Laya `choice` 对两个动作的概率分布 |
| 撞击风险 | Laya `noul`：P(这一步不拍翅会撞上管道/地面/顶端) |
| 紧急度 | Laya `score`：安全 / 需留意 / 危险 / 千钧一发 的期望档位 |

## 运行

```bash
# 交互模式（终端至少约 110 列 × 30 行）
uv run --extra demo python -m demos.flappy

# 常用参数
uv run --extra demo python -m demos.flappy --fps 20        # 决策节奏
uv run --extra demo python -m demos.flappy --seed 42       # 固定种子
uv run --extra demo python -m demos.flappy --strategy high # 起手就飞高（lazy/center/high）
uv run --extra demo python -m demos.flappy --unassisted    # 关闭安全护盾（裸模型）
uv run --extra demo python -m demos.flappy --headless --steps 600   # 无界面跑测
```

按键：`1/2/3` 切换飞行策略（省力 / 居中 / 飞高）· `Q` 退出 · `P` 暂停。

三种策略同时改变**喂给模型的目标提示词**和**几何层的可行动作边界**，实测
平均飞行高度（300 步 × 3 种子）：省力 6.1 行（会贴地滑行，最后时刻才拍翅）、
居中 12.4 行（始终卡缺口中央）、飞高 14.8 行（贴着缺口上沿飞）。切换后决策
日志里的原文会立即带上新的策略目标。权重从 `models/hub/laya-multilingual-mlx`
本地加载，运行期间零网络请求（面板 NETWORK OFFLINE ✓）。

界面分三栏：左侧棋盘，右侧决策面板（概率条/推理耗时），底部**模型决策日志**
滚动显示最近几步——每条的上行是当步喂给模型的完整原文，下行是模型输出的
拍/滑概率、实际执行的动作、护盾纠正标记（`[SHIELD]`）与撞击风险/紧急度。

## 模型决策 vs 护盾

这是与官方 Snake demo 相同的 **feature-assisted** 语义：

- **特征层（非模型）**：把棋盘数值算好喂给模型——鸟离地高度、缺口位置、
  以及"预演"：拍翅后离地 X 行距缺口 Y 行 / 滑翔后离地 X' 行距缺口 Y' 行。
- **模型真实决策**：在"可行动作集"内选择。可行动作集 = 执行该动作后，
  几何贪心仍能在 45 步内找到活路的动作。两个动作都可行时，执行模型的选择。
- **护盾（SHIELD）**：模型选择了不可行动作时，改执行可行动作并计数标记。
  两个动作都不可行时，如实执行模型选择（下一帧大概率 CRASH）。

对照实测（FP16，均值 ~6.9ms/决策，8 局 × 每局 400 步封顶）：

| 版本 | 结果 |
|---|---|
| 优化前提示词 + 护盾 | 800 步 0 死亡，48 管，护盾干预 74 次（≈9%） |
| 优化前裸模型 | 300 步死 6 次，最好 1 管 |
| **优化后（snake 式标注）裸模型** | **8 局仅 2 死，6 局跑满 400 步，平均 19.6 分** |
| **优化后 + 护盾** | **400 步 0 死亡 0 干预，23 管（该步数满分）** |
| 纯几何贪心（无模型，对照组） | 3000 步 0 死亡，185 管 |

优化关键：与官方 Snake 一致，把几何层的判定结果（哪个动作安全、哪个是朝缺口
调整的最佳动作）直接写进选项描述，让模型做它擅长的语义匹配，而不是让它自己
做空间算术。fp32 与 fp16 决策结果一致。
